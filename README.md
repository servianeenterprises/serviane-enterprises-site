# Serviane Enterprises website

This is a self-contained static website built with HTML, CSS and JavaScript. It has no framework, subscription, external font, analytics script, form processor or runtime dependency.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/` in a browser.

## Publish with GitHub Pages

Upload the contents of this folder to the root of a GitHub repository. In the repository's Pages settings, deploy from the `main` branch and its root folder. The included `CNAME` file configures `servianeenterprises.org`; `.nojekyll` tells GitHub Pages to serve the files exactly as provided.

## Contact behavior

The contact buttons use the visitor's email application. Messages are addressed to `servianeenterprises@gmail.com` with `paulhollar@servianeenterprises.org` copied. The site has no inquiry form, user account, online payment, analytics or advertising-cookie functionality.
